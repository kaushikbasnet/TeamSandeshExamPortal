2. Or type / paste questions

Type questions in the box (or copy them from Word) in this simple format, then press Check.

How to write it
  • [IQ] or [GK] on its own line starts that section.
  • Start each question with its number: 1. or Q1.
  • Options start with A. B. C. D. (or a), (a)).
  • Then the correct letter: Answer: C
  • Picture for the question: Picture: q5.png (upload it on the Pictures tab). An option can also be just a picture name, like A. shape1.png
  • Match the following: write List I: then its items one per line, then List II: and its items, then the options like A. A-2, B-1, C-4, D-3
